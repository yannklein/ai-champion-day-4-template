# Build brief

Replace everything in this file with the text of your build brief from Day 3,
Exercise 6, headings and all.

Paste the text, not a link. Your agent cannot open a Google Doc, so a link
here reads to it as an empty file, and an agent with no brief invents one.

Keep your own headings exactly as you wrote them: The product, Who it is
for, Screens, Design tokens, Components, Data shape, Automation, Links.
Every prompt for the rest of the day points at one of those sections by
name.
